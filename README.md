# 📝 Spendly
## 📍 Трекинг персональных расходов прямо в боте Telegram.

🤖 Spendly - Это ваш бот-помощник, который помогает вам в трекинге ваших личных расходов в жизни путём комфортной 
заполнения данных и автоматической их обработки нашим ботом, что позволяет вам в лишний раз не задумываться о лишних
мыслях и сконцентрироваться на других делах.

## 📍 Что вам доступно?
* ✅ Полный контроль над вашими расходами
* ✅ Записывайте расходы которых вы уже совершили
* ✅ Или запланируйте новые расходы и узнайте сколько у вас останется в конце
* ✅ Управление кнопками позволяет вам более комфортно работать (TODO)

## 📍 Для разработчиков
Этот проект является воплощением моих идей и решением моей проблемы.
Вы можете скопировать проект себе и внести свои изменения

Все уже добавленные основные функции вы можете посмотреть в файле [TODO](TODO.md)

Инструкция:

Пропишите данную команду, чтобы скопировать проект себе локально
```bash
git clone https://github.com/n0vember24/spendly
```

А затем, измените данные в файле .env, укажите в `BOT_TOKEN` токен своего бота от @BotFather
А так же по желанию можете указать новый `URL` для базы данных, но это опциально

После этого, вам нужно будет установить зависимости чтобы бот работал

В этом проекте я использовал технологию cMake, что позволяет более быстро и комфортно работать с проектом
Чтобы полностью установить все зависимости и запустить бота, используйте команду `make`

А если хотите сделать всё отдельно, можете воспользоваться этими командами:
```bash
# Чтобы установить зависимости
make install

# Чтобы сделать миграцию базы данных
make mgr

# Чтобы запустить бота
make run
```
